## Option A — "Archive"

A neutral, grounded palette inspired by physical filing systems and archive labels. Warm grey backgrounds with an **amber/gold** functional accent. Feels like a tool that means business.

| Role | Color | Hex |
|------|-------|-----|
| Stage background | warm white | `#f8fafc` |
| Index background | light grey | `#f1f5f9` |
| Body text | deep slate | `#1e293b` |
| Muted text | medium slate | `#64748b` |
| **Accent** | **amber** | **`#d97706`** |
| Accent hover | dark amber | `#b45309` |
| Active item bg | pale amber | `#fef3c7` |
| Active item text | dark amber | `#92400e` |
| Tags | slate-200 | `#e2e8f0` |
| Borders | slate-300 | `#cbd5e1` |
| **Destructive** | **red** | **`#dc2626`** |
| Delete hover bg | pale red | `#fee2e2` |

**Vibe:** Mature, utilitarian, warm but serious. The amber reads as "selected/highlighted" without looking like a brand color.

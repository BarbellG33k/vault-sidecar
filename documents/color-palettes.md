## Option A — "Archive"

A neutral, grounded palette inspired by physical filing systems and archive labels. Warm grey backgrounds with an **amber/gold** functional accent. Feels like a tool that means business.

| Role | Color | Hex |
|------|-------|-----|
| Stage background | warm white | `#f8fafc` |
| Index background | light grey | `#f1f5f9` |
| Body text | deep slate | `#1e293b` |
| Muted text | medium slate | `#64748b` |
| **Accent** | **amber** | **`#d97706`** |
| Accent hover | dark amber | `#b45309` |
| Active item bg | pale amber | `#fef3c7` |
| Active item text | dark amber | `#92400e` |
| Tags | slate-200 | `#e2e8f0` |
| Borders | slate-300 | `#cbd5e1` |
| **Destructive** | **red** | **`#dc2626`** |
| Delete hover bg | pale red | `#fee2e2` |

**Vibe:** Mature, utilitarian, warm but serious. The amber reads as "selected/highlighted" without looking like a brand color.

## Option C — "Meadow"

A soft, sun-drenched palette pulled from moss, morning dew, and dried wildflowers. Very pale mint backgrounds with **soft teal** accents and **warm dusty-rose** text. Gentle, breathable, unhurried.

| Role | Color | Hex |
|------|-------|-----|
| Stage background | pale mint | `#dff2d8` |
| Index background | soft sage | `#c6dea6` |
| Body text | dusty rose-brown | `#7a6263` |
| Muted text | warm taupe | `#9e8586` |
| **Accent** | **soft teal** | **`#7ebdc3`** |
| Accent hover | deeper teal | `#5da3aa` |
| Active item bg | pale teal wash | `rgba(126, 189, 195, 0.18)` |
| Active item text | deep teal | `#4a8a91` |
| Tags | pale olive | `#ced097` |
| Borders | sage tint | `#b8d4a8` |
| **Destructive** | **dusty brick** | **`#a67071`** |
| Delete hover bg | pale rose wash | `rgba(122, 98, 99, 0.1)` |

**Vibe:** Like working inside a greenhouse at golden hour. The teal pops without shouting, the mint background is easy on the eyes, and the dusty-rose text is warmer than slate without being harsh. Surprisingly readable and calm.

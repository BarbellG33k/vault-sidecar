Design Principles

The vault-sidecar project follows a few core principles that keep it lightweight and resilient.

Local-first

Your data lives in plain files on your machine. There is no database, no cloud lock-in, and no proprietary format.

"The entire site can be built into a folder of static files and hosted anywhere."

Markdown and HTML are the native tongues. Learn more.

function greet(name) {
  return `Hello, ${name}!`;
}

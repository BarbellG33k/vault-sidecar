Sample HTML Document

Demonstrating HTML isolation in vault-sidecar

What This Shows

HTML content in vault-sidecar renders inside a Shadow DOM. That means the styles in this document are completely isolated — they will never leak into the app chrome, and the app's CSS will never leak in here.

How It Works

The <html-isolator> custom element reads the raw HTML from a <script type="text/html"> tag, parses it, and injects it into an open Shadow Root attached to itself.

Use Cases

Full HTML documents are perfect for dashboards, reports, portfolios, or any content that needs its own layout and styling independent of the vault's reading interface.

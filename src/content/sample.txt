Sample Plain-Text Document
==========================

This is a sample .txt file demonstrating how vault-sidecar handles
plain-text content.

Unlike Markdown or HTML files, .txt documents are rendered as-is inside
a <pre> block with monospace formatting. No parsing, no transformation.

Use this format for:

  - Raw notes and scratchpads
  - Log files you want to archive
  - Text exports from other tools
  - Anything where formatting should be preserved exactly

Features of .txt in vault-sidecar:

  1. Front matter is optional (same as Markdown).
  2. The entire body is wrapped in a <pre class="text-content"> element.
  3. Syntax highlighting does not apply.
  4. Tags can still be defined in front matter for indexing.
